# Прототип Skillaz Start для VOXYS

Демо-прототип модуля адаптации Skillaz Start, наполненный контентом под аутсорсинговый
контакт-центр: план специалиста на 30 дней с обучением в учебном центре и аттестацией,
короткий план перехода на новый проект, оценочные листы в форме контроля качества,
риски по показателям качества и включённости наставника.

Методика и обоснование решений — в [METHOD.md](METHOD.md).

> Все данные в прототипе — демонстрационные. Имена сотрудников, названия площадок
> и проектов, показатели и суммы вымышлены и не отражают реальные данные клиента.

## Роли в прототипе

| Роль | Точка входа | Что показывает |
|---|---|---|
| Кандидат | `candidate/adaptation.html` | Пребординг: дойти до старта потока обучения |
| Сотрудник | `employee/adaptation.html` | План новичка: маршрут, цели, промежуточные результаты |
| Наставник | `assistant/plan.html` | Свои задачи в чужом плане, оценочные листы |
| Супервайзер | `manager/team.html` | Группа, риски, контрольные точки, финальное ревью |
| HR-админ | `hr/plans.html`, `hr/template.html` | Шаблоны, назначенные планы, очередь назначения, справочники |

Стартовая страница — `index.html`.

## Проверка страниц прототипа

`test/render-check.js` прогоняет HTML-страницу через Babel и рендерит её в jsdom
через настоящий React 18, проверяя, что `#root` не пустой и не было JS-ошибок.

### Установка (один раз)

```
npm install jsdom @babel/core @babel/preset-react react@18.3.1 react-dom@18.3.1
```

### Запуск

```
node test/render-check.js hr/template.html
node test/render-check.js manager/plan.html --query "employee=darya"
```

Известные ограничения харнесса (унаследованы от исходного прототипа, не связаны
с контентом VOXYS): `hr/vacancy-new.html` не рендерится в jsdom — страница использует
`IntersectionObserver`, которого в jsdom нет; часть `interaction-*.js` содержит
устаревшие ассерты.
